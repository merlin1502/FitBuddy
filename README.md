# FitBuddy - AI Fitness Plan Generator

## Project Overview

FitBuddy is an AI-powered fitness plan generator designed to help users create simple and personalized workout recommendations.

Users can select their fitness goal, fitness level, and number of workout days per week. The application then generates a suitable workout recommendation.

## Features

- Personalized fitness plan generation
- Multiple fitness goals
- Beginner, intermediate and advanced fitness levels
- Workout day selection
- Recommended exercises
- Responsive website design
- Simple and user-friendly interface

## Fitness Goals

The application supports:

- Weight Loss
- Muscle Gain
- General Fitness
- Strength

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

How It Works

1. Open the FitBuddy website.
2. Select your fitness goal.
3. Select your fitness level.
4. Select the number of workout days per week.
5. Click the "Generate My Plan" button.
6. The application displays a personalized workout recommendation.
